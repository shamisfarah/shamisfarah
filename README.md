## 🛠️ Featured projects & coursework

### 01 · Client-server communication with encryption

A Python project exploring bidirectional communication between a client and server using TCP sockets, Diffie-Hellman key exchange and AES encryption.

**Key concepts:** TCP networking · Key exchange · Symmetric encryption · Client-server architecture

[Explore my repositories →](https://github.com/shamisfarah?tab=repositories)

### 02 · British Library ransomware incident analysis

An undergraduate cybersecurity case study examining the 2023 ransomware incident, including attacker motivations, potential attack routes, security weaknesses and defensive recommendations.

**Key concepts:** Threat analysis · CIA triad · Cyber Kill Chain · Network segmentation · Incident recovery

### 03 · Data privacy and anonymisation

A Python practical using a credit dataset to explore generalisation and suppression, including age grouping, data exploration and visualisation.

**Key concepts:** Python · Data analysis · Data privacy · Anonymisation

### 04 · Algorithmic fairness and COMPAS

An analysis of a criminal justice risk assessment dataset, comparing prediction outcomes across demographic groups using confusion matrices and positive predictive value.

**Key concepts:** Data analysis · Confusion matrices · Algorithmic bias · Responsible AI

### 05 · Final-year research: Bias in facial detection

My undergraduate research explored potential sources of bias in facial detection systems, including dataset representation, evaluation across demographic groups and fairness considerations.

**Key concepts:** Research · Machine learning fairness · Data representation · Ethical technology
